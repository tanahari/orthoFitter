# 📘 OrthoFitter: ホワイトボックス型・自動基底選択システム

## 1. プロジェクトの背景とコンセプト

現代のAIやディープラーニングは、膨大なデータから高精度な予測をブラックボックスに弾き出すのが得意ですが、「なぜその予測になったのか」という科学的な解釈性や、物理法則との整合性を担保するのが難しいという課題があります。

一方で、人間（数学者・物理学者）は何百年もかけて、微分方程式の解釈や現象の本質を捉えるための「最強の関数辞書（直交関数カタログ：エルミート多項式、三角関数、ラゲール多項式など）」を築き上げてきました。

`OrthoFitter` は、AIをブラックボックスな「神」として使うのではなく、「人間が築いた数理物理のカタログを高速に試行錯誤・最適化し、真に支配的な少数の基底（数式のレシピ）を自律的にあぶり出す『ホワイトボックスなアシスタント（道具）』」として定義する次世代の数理物理×AIシステムです。

---

## 2. コア思想：物理法則を「教師」とする強化学習

本システムでは、あらかじめ「正解の解のデータ」を用意する教師あり学習は行いません。代わりに、「物理法則（微分方程式の残差）」そのものをAIのコンパス（報酬・評価基準）にします。

* **エージェント（探索エンジン）**：カタログからどの基底関数を採用し、どのような係数で組み合わせるかを選択する。
* **環境（微分方程式）**：対象とするスツルム・リウービル型などの微分方程式。
* **ジャッジメント（残差）**：エージェントが選んだ試行関数を微分方程式に代入し、「どこがどれくらい物理的に破綻しているか（残差）」を一瞬で評価する。

これにより、AIは「物理的に筋が良く、かつ方程式の残差を極限までゼロにする数式」を自力で発見します。

---

## 3. 数理のキモ：「完全に 0」と「 0.0001」の分離

美しいホワイトボックス（無駄な基底が入っていない最小限の数式）を構築するため、問題構造を2つのレイヤーに分けて攻略します。

1. **「0.0001（係数の微調整）」の世界**
* 選択された基底の係数 $c_n$ を滑らかに決定する領域。ここは数値最適化（勾配法など）によって高速に処理されます。


2. **「完全に 0（スパース性・ON/OFFの選択）」の世界**
* 「どの基底を使い、どれを完全に捨てるか」という離散的な組合せ選択の領域。無駄な項を完全にゼロに落とし込み、現象の本質を突くミニマルな数式を抽出します。



---

## 4. 全体ワークフロー

```
[ 微分方程式 (例: エルミート微分方程式) ]
         ↑
[ 評価器 (残差を計算) ] <--- [ 報酬 = 方程式の残差 + スパース性ペナルティ ]
         ↑
[ AI / 探索エンジン ] ---> カタログから基底と係数のレシピを出力

```

1. **カタログの参照**：エルミート多項式などの直交系からベースとなる関数群を準備。
2. **係数の最適化**：指定されたパラメータ（例: $\lambda = 2$）に対し、残差が最小になる係数レシピを探索。
3. **ホワイトボックスな出力**：結果をブラックボックスなテンソルではなく、「どの基底がどれくらいの寄与度で組み合わされているか」の数式（スペクトル分解）として出力。
